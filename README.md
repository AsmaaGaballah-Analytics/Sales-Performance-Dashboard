# 📊 Sales Data Analysis & Executive Dashboard

> A comprehensive data analysis project focused on cleaning, transforming, and visualizing sales data to extract actionable business insights, track key performance indicators (KPIs), and evaluate revenue performance.

---

## 🚀 Project Overview
This project involves transforming raw sales records into an interactive, executive-level dashboard. The primary goal is to streamline data processing, evaluate product category performance, and present clear visualizations to support strategic business decisions.

---

## ✨ Key Features
* **Data Cleaning & Transformation:** Utilized Power Query to handle missing values, remove duplicates, and structure raw datasets for analysis.
* **Advanced Data Modeling:** Built dynamic Pivot Tables and generated custom calculated fields to track revenue, profit margins, and order trends.
* **Interactive Filtering:** Integrated slicers and filters to seamlessly explore data by product category, customer segment, and timeline.
* **Executive Visualization:** Designed clean, professional clustered column charts, bar charts, and line charts for an intuitive overview.

---

## 🛠️ Tools & Technologies
* **Microsoft Excel:** Data processing, Power Query, and Pivot Tables.
* **Data Visualization:** Clustered Column Charts, Bar Charts, and Interactive Dashboard Design.
